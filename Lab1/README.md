# LAB 1 - Bắt gói tin Telnet - SSH

## 1. Thông tin sinh viên

- Họ và tên: Lê Nguyễn Đăng Khoa
- MSSV: 1150070021
- Lớp: 11_ĐH_TMĐT

## 2. Nội dung thực hiện

- Cài đặt Ubuntu Server.
- Cấu hình SSH Server.
- Kết nối SSH từ Kali Linux.
- Sử dụng Wireshark bắt gói tin SSH.
- Lọc gói tin bằng `tcp.port == 22`.
- Sử dụng Follow TCP Stream để phân tích lưu lượng.

## 3. Kết quả

- SSH Server hoạt động trên TCP port 22.
- Kết nối SSH thành công.
- Wireshark bắt được lưu lượng SSH.
- Dữ liệu SSH không hiển thị mật khẩu và lệnh dưới dạng plaintext.
